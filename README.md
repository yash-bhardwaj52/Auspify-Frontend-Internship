# Auspify Frontend Development Internship

A collection of frontend development projects completed during my **Frontend Development Internship at Auspify Technologies**.

The projects cover responsive web design, interactive interfaces, JavaScript functionality, API integration, React development, data visualization, reusable components, and responsive dashboard design.
